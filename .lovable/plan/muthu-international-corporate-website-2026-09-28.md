# Muthu International corporate website

## Goal
Build the complete premium, multi-page B2B manufacturer website described in the supplied brief, using its exact navy, champagne, ivory, beige, charcoal, grey, white, and border palette.

## Experience
- Establish an editorial, international-fashion look with strong typography, cinematic garment and factory imagery, generous space, and restrained gold accents.
- Add a compact sticky desktop navigation, animated mobile menu, shared footer, page transitions, image/text reveals, hover motion, and reduced-motion support.
- Keep every page responsive at desktop, tablet, and mobile sizes with no dead controls or placeholder links.

## Pages and content
- Build Home, About, Products, dynamic Product Detail, Manufacturing, Design & Development, OEM / Private Label, Quality, Sustainability, Collections, Gallery, Contact, and Request a Quote.
- Make products, collections, gallery, processes, milestones, and certifications data-driven from reusable content modules.
- Use editable factual placeholders where the brief does not provide company history, certifications, sustainability facts, address, phone, WhatsApp, email, or social links.
- Add filterable product and gallery views, product galleries/details, manufacturing and quality timelines, collection layouts, and validated enquiry forms with clear success states.

## Assets
- Generate a cohesive set of premium editorial kidswear and factory-craftsmanship imagery; no retail/cart styling, cartoons, cheap stock imagery, or unsupported claims.
- Use purposeful responsive crops, lazy loading below the first screen, and descriptive alternative text.

## Structure and quality
- Create reusable navigation, footer, buttons, headings, animated reveal, image, product, collection, gallery, timeline, form, page hero, and CTA pieces.
- Add unique page titles, descriptions, Open Graph fields, semantic structure, and appropriate organization/manufacturer structured data.
- Verify all routes, navigation, filters, forms, mobile menu, desktop/mobile layouts, browser console, and current preview build.

## Technical details
- Keep TanStack Start routing and Tailwind CSS v4.
- Store all design values as semantic tokens in the global design system.
- Use lightweight CSS and IntersectionObserver-based motion rather than adding a large animation dependency.
- Keep content prepared for a future CMS without adding a database or admin interface now.
